# Plan: Licensing, Attribution, About Window & README

## Context
The project has no LICENSE file, no third-party attribution, no Help->About window, and no README.md. This plan adds all four to properly attribute vendors, declare our own license, provide in-app license info, and create a project front page.

---

## 1. Create `LICENSE` at project root
Standard MIT license with:
- Copyright (c) 2026 Rodion Radchenko and mdCAD contributors

## 2. Create `scripts/gather_licenses.py`
Python script that:
- Scans `vendors/` subdirectories and CMake FetchContent build dirs (`build/_deps/`) for LICENSE/COPYING files
- Falls back to known hardcoded license data when files aren't found (common when vendors are fetched at build time)
- Outputs `THIRD_PARTY_LICENSES.md` at project root
- Covers: Sokol (zlib/libpng), Dear ImGui + cimgui (MIT), Flecs (MIT), cJSON (MIT)

## 3. Create `THIRD_PARTY_LICENSES.md` at project root
Generated by the script (but also committed as a static file). Contains for each vendor:
- Library name + URL
- License type
- Copyright line
- Full license text

Libraries:
| Library | License | Copyright |
|---------|---------|-----------|
| Sokol | zlib/libpng | (c) Andre Weissflog |
| Dear ImGui | MIT | (c) 2014-2024 Omar Cornut |
| cimgui | MIT | (c) Stephan Dilly / cimgui contributors |
| Flecs | MIT | (c) Sander Mertens |
| cJSON | MIT | (c) 2009-2017 Dave Gamble and cJSON contributors |

## 4. Create `src/ui/ui_about.h` — Help->About ImGui window
Header-only module following project conventions (`static inline` functions, include guard).

**State struct:** `ui_about_state_t` with `bool window_open`

**Functions:**
- `ui_about_init(state)` — initialize
- `ui_about_draw_menu(state)` — draws the "Help" menu in the menu bar (call from `ui_scene_hierarchy.h`)
- `ui_about_draw(state)` — draws the About window when open

**Window contents:**
- App name "mdCAD" + version from CMakeLists (0.1.0)
- "Licensed under the MIT License" + copyright line
- Separator
- Collapsing headers for each third-party library with name, license type, copyright, and URL
- A "Close" button

**Integration in `ui_scene_hierarchy.h`:**
- Add `#include "ui_about.h"`
- Add `ui_about_state_t about;` to `ui_scene_hierarchy_state_t`
- Call `ui_about_init()` in `ui_scene_hierarchy_init()`
- Add Help menu after Edit menu (before `ui_scene_hierarchy_draw_add_menu`): call `ui_about_draw_menu(&state->about)`
- Call `ui_about_draw(&state->about)` alongside other UI draws

**No changes needed to `app.c`** — the about state lives inside the scene hierarchy state.

## 5. Create `README.md` at project root
Concise project front page composed from existing docs:

- **Header**: mdCAD name + one-line description
- **Features**: Condensed list from CHECKPOINT.md "Current Features"
- **Screenshot placeholder**: `<!-- screenshot -->` comment
- **Quick Start**: Abbreviated build commands (macOS, Windows, Web) with link to `docs/QUICKSTART.md`
- **Platform Support**: Table from CHECKPOINT.md
- **Architecture**: Brief overview (ECS + Sokol + ImGui), link to `docs/ECS_RENDERING_PRIMER.md`
- **Third-Party Libraries**: Table with links, reference to `THIRD_PARTY_LICENSES.md`
- **License**: MIT, link to `LICENSE`
