# Codebase Structure

**Analysis Date:** 2026-03-24

## Directory Layout

```text
mdCAD/
├── CHANGELOG.md              # Archived session summaries and delivered changes
├── CMakeLists.txt            # Top-level CMake configuration
├── README.md                 # Project overview and quick start
├── .planning/                # Active GSD planning, state, and codebase maps
├── android/                  # Android Gradle project and NativeActivity glue
├── build/                    # Local macOS + Ninja build output used on this machine
├── docs/                     # Developer docs, quickstart guides, and legacy archive
├── ios/                      # iOS bundle resources and Xcode support files
├── scripts/                  # Utility scripts, browser tests, and shader tooling
├── src/                      # Application source and header-only modules
├── vendors/                  # Vendored third-party dependencies
└── web/                      # Emscripten shell/template assets
```

## Directory Purposes

**`src/`:**
- Purpose: Main application code and most runtime modules
- Contains: `*.c`, `*.h`, Objective-C source for Apple readback, and shader assets
- Key files: `src/app.c`, `src/platform.h`, `src/CMakeLists.txt`, `src/scene_serializer.h`, `src/ecs/ecs_scene.h`, `src/ecs/ecs_world.h`, `src/gpu/geometry_batch.h`, `src/ui/ui_scene_hierarchy.h`
- Subdirectories: `src/components/`, `src/ecs/`, `src/gpu/`, `src/gizmo/`, `src/shaders/`, `src/shaders/spirv/`, `src/ui/`

**`src/components/`:**
- Purpose: ECS component definitions and factory helpers
- Contains: Geometry, transform, renderable, selectable, light, and label components
- Key files: `src/components/geometry_comp.h`, `src/components/transform_comp.h`, `src/components/light_comp.h`
- Subdirectories: None

**`src/ecs/`:**
- Purpose: ECS world creation and high-level scene API
- Contains: World setup, component registration, entity helpers, parent/child logic
- Key files: `src/ecs/ecs_world.h`, `src/ecs/ecs_scene.h`
- Subdirectories: None

**`src/gpu/`:**
- Purpose: GPU batch managers, instance buffers, pick buffer logic, and backend-specific readback
- Contains: Rendering infrastructure and platform-specific CPU readback implementations
- Key files: `src/gpu/geometry_batch.h`, `src/gpu/instance_buffer.h`, `src/gpu/pick_buffer.h`, `src/gpu/pick_readback.h`, `src/gpu/pick_readback_metal.m`, `src/gpu/pick_readback_d3d11.c`, `src/gpu/pick_readback_vulkan.c`, `src/gpu/pick_readback_opengl.c`
- Subdirectories: None

**`src/gizmo/`:**
- Purpose: Translation gizmo rendering and interaction
- Contains: Gizmo state machine, vertex edit mode, and overlay rendering
- Key files: `src/gizmo/gizmo.h`, `src/gizmo/gizmo_rendering.h`, `src/gizmo/gizmo_vertex_mode.h`
- Subdirectories: None

**`src/ui/`:**
- Purpose: ImGui windows and editor panels
- Contains: Scene hierarchy, viewport, inspector, visibility, debug, theme, and about windows
- Key files: `src/ui/ui_scene_hierarchy.h`, `src/ui/ui_entity_inspector.h`, `src/ui/ui_viewport.h`, `src/ui/ui_visibility.h`, `src/ui/ui_controls.h`
- Subdirectories: None

**`src/shaders/`:**
- Purpose: Shader source for all supported backends
- Contains: Text shader definitions plus Vulkan-only SPIR-V assets
- Key files: `src/shaders/instanced_line_shaders.h`, `src/shaders/instanced_triangle_shaders.h`, `src/shaders/join_shaders.h`, `src/shaders/pick_shaders.h`
- Subdirectories: `src/shaders/spirv/`

**`src/shaders/spirv/`:**
- Purpose: Vulkan shader sources, compiled bytecode, and generated bytecode headers
- Contains: `*.vert`, `*.frag`, `*.spv`, and `spirv_bytecode.h`
- Key files: `src/shaders/spirv/spirv_bytecode.h`
- Subdirectories: None

**`scripts/`:**
- Purpose: Utility scripts, automated browser tests, packaging helpers, and shader build tooling
- Contains: Node scripts, Python utilities, and Windows shader build scripts
- Key files: `scripts/debug-wasm.mjs`, `scripts/test-imgui.mjs`, `scripts/gather_licenses.py`, `scripts/obj_to_colored_ply.py`, `scripts/vulkan-win/build-all.ps1`
- Subdirectories: `scripts/vulkan-win/`, `scripts/test-output/`

**`vendors/`:**
- Purpose: Vendored third-party libraries used by the build
- Contains: Source and CMake files for Sokol, Flecs, cimgui, and cJSON
- Key files: `vendors/CMakeLists.txt`, `vendors/libsokol/sokol.c`, `vendors/flecs/flecs.c`, `vendors/cjson/cJSON.c`, `vendors/libcimgui/CMakeLists.txt`
- Subdirectories: `vendors/libsokol/`, `vendors/flecs/`, `vendors/cjson/`, `vendors/libcimgui/`

**`android/`:**
- Purpose: Android Gradle project that wraps the main CMake build
- Contains: Gradle settings, application module, JNI CMake wrapper, manifest, and launcher assets
- Key files: `android/build.gradle.kts`, `android/settings.gradle.kts`, `android/app/build.gradle.kts`, `android/app/src/main/cpp/CMakeLists.txt`, `android/app/src/main/AndroidManifest.xml`
- Subdirectories: `android/app/`, `android/gradle/`, `android/app/src/main/res/`

**`ios/`:**
- Purpose: iOS bundle resources and launch screen assets
- Contains: Info plist and storyboard resources for Xcode packaging
- Key files: `ios/Info.plist`, `ios/LaunchScreen.storyboard`
- Subdirectories: None

**`web/`:**
- Purpose: Emscripten shell template and browser bootstrap assets
- Contains: HTML shell used during web builds
- Key files: `web/shell.html`
- Subdirectories: None

**`docs/`:**
- Purpose: Developer-facing documentation
- Contains: Quick start and architecture notes plus `docs/legacy/pre-gsd-agent-workflow/` for frozen pre-GSD agent docs
- Key files: `docs/QUICKSTART.md`
- Subdirectories: None

**`.planning/`:**
- Purpose: Active planning, continuity, roadmap, and codebase reference area for the current GSD workflow
- Contains: `STATE.md`, roadmap/requirements artifacts, quick-task plans, and active codebase maps
- Key files: `.planning/STATE.md`, `.planning/ROADMAP.md`, `.planning/codebase/STRUCTURE.md`, `.planning/codebase/CONVENTIONS.md`
- Subdirectories: `.planning/phases/`, `.planning/quick/`, `.planning/codebase/`, `.planning/milestones/`

## Key File Locations

**Entry Points:**
- `src/app.c`: Single runtime entry point through `sokol_main()`
- `src/CMakeLists.txt`: Produces the `mdCAD` executable or shared library depending on platform
- `android/app/src/main/cpp/CMakeLists.txt`: Android Gradle wrapper that adds the main project

**Configuration:**
- `CMakeLists.txt`: Top-level project and build-type configuration
- `src/CMakeLists.txt`: Source list, platform-specific sources, and linker options
- `src/platform.h`: Backend selection by platform/compiler macros
- `web/shell.html`: Emscripten shell template
- `ios/Info.plist`: iOS bundle metadata

**Core Logic:**
- `src/app.c`: Runtime orchestration, scene setup, frame loop, picking, gizmo, and shutdown
- `src/ecs/ecs_world.h`: ECS world setup and component registration
- `src/ecs/ecs_scene.h`: Scene API, entity creation, transforms, and draw/pick integration
- `src/gpu/geometry_batch.h`: Batch managers for lines, points, and triangles
- `src/scene_serializer.h`: Scene JSON save/load
- `src/ui/ui_scene_hierarchy.h`: Hierarchy panel, file actions, and import workflows

**Testing:**
- `scripts/test-imgui.mjs`: Puppeteer-driven ImGui interaction test
- `scripts/debug-wasm.mjs`: Web build debug harness and screenshot capture
- `scripts/test-output/`: Generated screenshots and test artifacts

**Documentation:**
- `README.md`: Project introduction and quick start
- `docs/QUICKSTART.md`: Build and run instructions by platform
- `.planning/STATE.md`: Active project state and continuity entry point
- `docs/legacy/pre-gsd-agent-workflow/`: Frozen pre-GSD workflow archive
- `CHANGELOG.md`: Archived session summaries

## Naming Conventions

**Files:**
- `*.h` and `*.c` for runtime modules and platform glue
- `*.m` for Objective-C source on Apple platforms
- `*.md` for documentation
- `*.mjs` for browser automation scripts
- `*.ps1` and `*.sh` for platform-specific tooling

**Directories:**
- Lowercase, descriptive directory names such as `src/`, `docs/`, `scripts/`, `vendors/`
- Feature groupings under `src/` such as `components/`, `ecs/`, `gpu/`, `gizmo/`, `ui/`, and `shaders/`

**Special Patterns:**
- `ui_*.h` for ImGui panels and windows
- `*_comp.h` for ECS component definitions
- `*_job.h` for incremental import workflows
- `pick_readback_*.c` and `pick_readback_*.m` for backend-specific readback implementations
- `spirv/` for Vulkan-only shader artifacts

## Where to Add New Code

**New Feature:**
- Primary code: `src/` for runtime logic, usually split into the relevant feature subdirectory
- Tests: `scripts/` for browser or tooling checks when applicable
- Config if needed: `CMakeLists.txt`, `src/CMakeLists.txt`, or platform-specific wrappers under `android/`, `ios/`, or `web/`

**New Component/Module:**
- Implementation: `src/components/` for components, `src/ecs/` for scene/ECS helpers, `src/gpu/` for rendering internals, `src/ui/` for panels
- Types: The same module header unless the feature needs a shared component factory in `src/components/`
- Tests: Add ad hoc verification scripts under `scripts/` if needed

**New Route/Command:**
- This repo does not have CLI routes; user-facing actions usually belong in `src/ui/` panels or `src/app.c`
- Handler: Add the interaction logic beside the panel/module that owns the state
- Tests: `scripts/test-imgui.mjs` or a new browser script under `scripts/`

**Utilities:**
- Shared helpers: `src/` near the subsystem that uses them, or `scripts/` if they are build-time tools
- Type definitions: `src/components/` for scene data, or the owning subsystem header

## Special Directories

**`build/`:**
- Purpose: Local Ninja build output used on this machine
- Source: Generated by CMake/Ninja, currently the active macOS workflow
- Committed: No

**`src/shaders/spirv/`:**
- Purpose: Vulkan shader sources and generated bytecode
- Source: Some files are checked in as compiled artifacts for the Vulkan path
- Committed: Yes

**`scripts/test-output/`:**
- Purpose: Browser-test screenshots and temporary artifacts
- Source: Generated by `scripts/debug-wasm.mjs` and `scripts/test-imgui.mjs`
- Committed: No
