# Quick Task 260526-f53: Persist the selected user theme in the active ImGui ini file

## Goal

Keep `UI_THEME_DEFAULT` as the startup fallback, but persist and restore the user's last selected theme through the same active ImGui settings stream (`imgui.ini`, `imgui.embedded.ini`, or `imgui.embedded.viewport-only.ini`) so direct ini edits in embedded scenarios also take effect on next launch.

## Task 1

- **files:** `src/imgui_storage.h`, `src/ui/ui_theme.h`, `src/app.c`
- **action:** Add theme persistence to the existing ImGui settings pipeline by registering a custom ImGui settings handler in `imgui_storage.h` before any ini load occurs, storing a stable theme token in the same ini data stream that already handles layout persistence, and restoring it via `ui_theme_apply(...)` when present. Keep `UI_THEME_DEFAULT` as the no-settings fallback, do not introduce a separate config file, and make sure the handler works for both standalone automatic `imgui.ini` persistence and the two embedded manual-memory ini variants.
- **verify:** `cmake --build build-vulkan --config Release --target mdCAD`
- **done:** Launches with shad-ui when no theme entry exists, but a saved or manually edited theme entry in the active ImGui ini file overrides that default on the next run in standalone, embedded, and viewport-only embedded modes.

## Task 2

- **files:** `src/ui/ui_controls.h`, `src/tests/theme_persistence_contract_test.c`, `src/CMakeLists.txt`
- **action:** Update the Controls theme combo to mark ImGui settings dirty after `ui_theme_apply(...)` so runtime theme changes are flushed back into the active ini file, then add a focused regression target that locks the contract around handler registration, default-before-restore behavior, and save triggering without widening this task into broader UI work.
- **verify:** `cmake --build build-vulkan --config Release --target mdCAD theme_persistence_contract_test && ctest --test-dir build-vulkan -C Release --output-on-failure -R "theme_persistence_contract_test|embed_layout_state_test"`
- **done:** Changing the theme from Controls schedules persistence, the build stays green, and a targeted regression test guards the shared ini-based theme persistence contract.
