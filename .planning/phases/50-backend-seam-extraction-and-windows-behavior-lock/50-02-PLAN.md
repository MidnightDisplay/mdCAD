<objective>
Move the Windows-only lifecycle implementation behind the internal backend seam and reduce `MdCadEmbeddedControl` to a shared shell without changing shipped Windows behavior.

Purpose: This is the core Phase 50 refactor. Per D-01 through D-07, the work must reorganize ownership only: same runtime lookup, same `--embedded --parent-hwnd` launch path, same relaunch sequencing, same sealed/diagnostic behavior.
Output: `WindowsMdCadEmbedBackend` owns the native lifecycle, `MdCadEmbeddedControl` becomes a thin shell, and `MdCadSessionCoordinator` talks to the backend instead of raw Win32 state.
</objective>
