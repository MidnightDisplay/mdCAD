## Accomplishments

- Added `MdCadRefreshWindowsRuntime` plus narrowly scoped helper/build/runtime properties to `samples/avalonia-mdcad-control/MdCad.Avalonia.Control.csproj`.
- Added a guarded `AfterTargets="Build"` target that runs only when:
  - `$(OS)` is `Windows_NT`
  - `$(DesignTimeBuild)` is not true
  - `MdCadRefreshWindowsRuntime=true`
- Wired the target to invoke `MdCad.WindowsRuntimeRefresh` with explicit absolute paths for repo root, `build-vulkan`, the committed runtime bundle, and the current control build output `mdcad-runtime` directory.
- Ran the control build with `-p:MdCadRefreshWindowsRuntime=true` and verified:
  - the helper message appeared only for the opt-in build,
  - `build-vulkan\bin\Release\mdCAD.exe`, `samples\avalonia-mdcad-control\runtime\win-x64\mdCAD.exe`, and `samples\avalonia-mdcad-control\bin\Release\net10.0\mdcad-runtime\mdCAD.exe` matched,
  - a deliberately newer output `imgui.embedded.ini` marker survived the build unchanged.
- Ran a plain control build immediately afterward and confirmed the helper target stayed inactive.
- Updated `52.1-VALIDATION.md` row `52.1-02-01` to green.

- Proved `.ini` preservation by protecting a newer output marker rather than assuming the helper’s copy policy was enough.
