## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Tight glyph-label and inline status gaps |
| sm | 8px | Default compact row spacing in ConstraintManager/filter bar |
| md | 16px | Default control spacing in popups and manager rows |
| lg | 24px | Subsection separation (filters vs. list vs. actions) |
| xl | 32px | Major section break inside inspector |
| 2xl | 48px | Large panel breathing room (rare) |
| 3xl | 64px | Full-window major separation (rare) |

Exceptions: viewport constraint glyph interactive hit area may exceed visual glyph size; enforce a minimum 20px pickable hit region for hover/select reliability.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #303446 | Main panels/windows and inspector background surfaces |
| Secondary (30%) | #414559 | ConstraintManager rows, popup frames, nested containers, input frames |
| Accent (10%) | #BABBF1 | Active constraint row, selected glyph emphasis, editable dimension value focus, in-context constraint menu current-item emphasis |
| Destructive | #E78284 | Delete constraint actions and delete confirmations only |

Accent reserved for: selected/hovered constraint glyph highlight, selected ConstraintManager row, active in-context menu item, focused LENGTH/ANGLE value editor, and driven-state emphasis badge. Do not use accent for neutral labels/body text.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Add Constraint |
| Empty state heading | No constraints yet |
| Empty state body | Select sketch geometry, press C to open applicable constraints, then apply one to define sketch behavior. |
| Error state | Constraint could not be applied to the current selection. Check entity types/selection count, then try again with a legal combination. |
| Destructive confirmation | Delete constraint: `Delete selected constraint? Participating geometry will remain; this only removes the constraint.` |

Additional destructive actions in this phase scope:
- Single-delete in ConstraintManager row: reuse the same confirmation copy above.
- Multi-delete (if batch deletion is later exposed in this phase): `Delete {N} selected constraints? This action can be undone in one step.`

Driven-state copy contract (CONS-05):
- Toggle label: `Driven`
- Tooltip/help: `Driven constraints remain visible/readable but do not drive solve equations.`
