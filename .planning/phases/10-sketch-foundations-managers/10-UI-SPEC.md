## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Tight inline spacing, status dot-to-label gap |
| sm | 8px | Default control gap inside manager rows |
| md | 16px | Default section spacing between controls |
| lg | 24px | Group/panel subsection separation |
| xl | 32px | Major subsection break inside inspector |
| 2xl | 48px | Large panel breathing space (rare) |
| 3xl | 64px | Full-window major separation (rare) |

Exceptions: existing global ImGui theme uses 6px `ItemSpacing.y` / `ItemInnerSpacing` in compact rows; keep for consistency with current panel style (source: `src/ui/ui_theme.h`).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #303446 | Window/panel background surfaces (Catppuccin Frappé base; source: `ui_theme.h`) |
| Secondary (30%) | #414559 | Nested sections, row/container surfaces, input frames |
| Accent (10%) | #BABBF1 | Active selection, focused controls, sketch status emphasis, primary phase CTA |
| Destructive | #E78284 | Delete actions and destructive confirmations only |

Accent reserved for: selected GeometryManager rows, active multi-select action controls, fixed-status emphasis badge/chip, `Create Sketch` primary action highlight, and undo-success emphasis text. Do not use accent for neutral body copy or passive borders.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Create Sketch |
| Empty state heading | No geometry in this sketch |
| Empty state body | Add Point, Line, or Arc/Circle from Add Entity or GeometryManager controls to start defining this sketch. |
| Error state | Sketch action could not be applied. Verify selection is still valid, then retry. If needed, use Undo to return to the previous state. |
| Destructive confirmation | Delete geometry: `Delete selected geometry from this sketch? This action can be undone in one step.` |

Additional destructive actions in phase scope:
- Single-delete geometry row action: same confirmation pattern as above.
- Multi-delete geometry action: `Delete {N} selected geometry items from this sketch? This will be one undo step.`

Status labels (locked): `solved`, `loose`, `fixed`, `error` (source: D-08 in 10-CONTEXT.md).
