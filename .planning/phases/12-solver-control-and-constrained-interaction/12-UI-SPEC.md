## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Tight inline gaps in status rows (`Status`, `Backend`, level badge + timestamp) |
| sm | 8px | Vertical spacing between control rows (`Auto-solve`, `Recalculate`, backend line) |
| md | 16px | Default section spacing inside SketchManager solver block |
| lg | 24px | Separation between solver controls and diagnostics/history region |
| xl | 32px | Separation between SketchManager and sibling manager blocks |
| 2xl | 48px | Large panel breathing room in full inspector layout |
| 3xl | 64px | Page/workspace-level spacing only; not used inside compact popups |

Exceptions: viewport implication markers and constraint glyph anchors keep constant-screen-size behavior from existing viewport UX; use a minimum 16px clickable hit region around glyph anchors.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 | 1.5 |
| Label | 13px | 600 | 1.4 |
| Heading | 20px | 600 | 1.2 |
| Display | 28px | 600 | 1.2 |

Usage contract:
- Use Body for diagnostics rows, helper copy, and empty-state body.
- Use Label for control captions, level badges (`INFO/WARNING/ERROR`), and inline metadata.
- Use Heading for `SketchManager` and `Solver` section headings.
- Use Display only for high-emphasis error-state banner in viewport overlay when constrained movement is blocked.

Defaulted for this phase (not specified upstream): 4-size scale, 2-weight limit.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #1E1E1E | Inspector background and default panel surfaces |
| Secondary (30%) | #2A2D2E | Collapsing headers, diagnostics container, row hover surfaces |
| Accent (10%) | #4DA3FF | Active `Auto-solve` toggle state, primary `Recalculate` action, selected implicated constraint row, implication outline emphasis |
| Destructive | #D64545 | `ERROR` severity emphasis and destructive confirmations (`Clear Diagnostics History`) |

Accent reserved for: active solve controls, selected implicated constraint target, diagnostics focus chips, and constrained-interaction failure highlight accents only.

Do not use accent for all interactive controls; secondary/neutral styling remains default for non-primary actions.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Recalculate Sketch |
| Empty state heading | No solver diagnostics yet |
| Empty state body | Run **Recalculate Sketch** or edit sketch geometry/constraints to generate diagnostics for this sketch. |
| Error state | Solver could not satisfy current constraints. Review highlighted constraints/geometries, adjust values or driven state, then recalculate. |
| Destructive confirmation | Clear Diagnostics History: Clear all saved solver diagnostics for this sketch? This action cannot be undone. |

Additional interaction copy contract for D-11 feedback path:
- Viewport toast on unsatisfiable drag: `Movement blocked by active constraints.`
- Diagnostics row message on unsatisfiable drag: `Drag rejected: active constraints make this move invalid.`
- Auto-focus helper line after failure: `Focused first implicated constraint.`

Source: 12-CONTEXT.md D-01..D-11 + defaults where wording was discretionary.
