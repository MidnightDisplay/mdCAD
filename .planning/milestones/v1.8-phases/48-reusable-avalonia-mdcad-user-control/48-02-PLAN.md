<objective>
Ship the pinned runtime bundle and deterministic output-copy/runtime-resolution seam that makes the reusable control self-contained for external Windows Avalonia apps.

Purpose: D-05 through D-08 explicitly forbid repo-root discovery and consumer-side mdCAD builds. This plan turns the library into a self-packaging control that always launches the copied stable runtime bundle from consumer output.
Output: A curated repo-owned runtime folder, `.gitignore` allow-list, maintainer refresh script, MSBuild copy metadata, sample-host `ProjectReference`, and `MdCadRuntimeResolver`.
</objective>
